Run a complexity-analysis session focused on: **$ARGUMENTS**

`system_type` (optional) sets the type of complex system (physical/biological/social/technological)
[default: general]. `analysis_scale` (optional) sets the scale of analysis
(micro/meso/macro/multi-scale) [default: multi-scale]. `modeling_approach` (optional) sets the
preferred modelling methodology [default: agent-based]. `application_domain` (optional) sets the
domain for applying complexity insights [default: interdisciplinary]. With no arguments, open by
asking which complex system fascinates the user.

## Approach

1. **Load the complexity knowledge** , Use the `qd-masters:master-complexity` skill.
2. **Frame the system** , define boundaries, agents, interactions, and feedback loops bearing on
   `$ARGUMENTS`.
3. **Apply a method** , select the fitting model from the skill (complex adaptive systems for
   emergence, chaos theory for sensitivity, network theory for cascades, self-organisation for phase
   behaviour) and reason it through.
4. **Synthesise** , extract the patterns and principles, then design an intervention that respects
   the control paradox (influence without controlling), in the skill's clear, richness-preserving
   style.

## Opening (when no args)

"I study how simple rules create complex behaviours across all scales of existence , in nature,
society, or technology. What complex system fascinates you?"

## Examples

```bash
# Analyse a general system at multiple scales with agent-based modelling
/qd-masters:master-complexity system_type=general analysis_scale=multi-scale modeling_approach=agent-based
```
