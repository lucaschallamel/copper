# Rule 05 - Architecture Guidelines

Cloud-native applications follow the Twelve-Factor App; distributed systems use the established
microservices patterns, designed for scalability, resilience, observability, performance and
security.

Read `skills/architecture-documentation/resources/architecture-guidelines-reference.md` before
designing a service, choosing a pattern or writing an ADR. **[RAT] [TR]** Every significant
architectural decision is an ADR: read `rules/05a-adr.rules.md` before writing one. Test and quality
targets: `rules/02a-code.rules.md`.
